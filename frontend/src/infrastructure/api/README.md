# API 서비스 설명

## 현재 상태

### ✅ 날씨 API (활성화)
- **서비스**: OpenWeatherMap
- **상태**: 실제 API 사용 중
- **API 키**: `.env` 파일에 설정됨
- **기능**: 현재 날씨, 미세먼지 정보

### ⏸️ 교통 API (일시 중지)
- **상태**: Mock 데이터 사용 중
- **이유**: API 링크 문제로 인해 일시 중지
- **기능**: Mock 데이터로 동작 (랜덤 도착 시간)

## 사용 방법

### 날씨 정보
1. 루틴 추가 시 "날씨" 또는 "미세먼지" 선택
2. 위치(위도/경도) 설정
3. 실제 날씨 정보 수신

### 교통 정보
1. 루틴 추가 시 "버스" 또는 "지하철" 선택
2. Mock 데이터로 동작 (실제 API 연동 대기 중)

## 향후 계획

교통 API 링크 문제 해결 후:
- 실제 버스 도착 정보 연동
- 실제 지하철 도착 정보 연동
